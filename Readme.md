!Имя проекта: SOlveSquare


!Описание проекта: Программа предназначена для решения полных и неполных квадратных уравнений, с вещественными коэффициентами. Поддерживает три режима работы, поддерживает тестирование и запись результатов в текстовый документ.


!Возможности:
1) Решение полных и неполных квадратных уравнений
2) Два режима ввода коэффициентов уравнения
3) Поддерживает тестирование программы.
4) Возможность запускать команду с аргументами командной строки
5) Сохранение результатов в файл "solver_results.txt"
6) Цветной вывод в терминал
7) Обработка ошибок ввода
8) Возможность выбора для выхода из программы или продолжение


!Режимы работ:
             1) Coefficient: отедльный ввод коэффициентов и получение результатов и их запись в текстовый документ "solver_results.txt"
             2) Complete: ввод полного квадратного уравнение и получение результатов и их запись в текстовый документ "solver_results.txt"
             3) test: поддерживает два режима: 3.1) Использование случайных коэффициентов лежащих в диапазоне [-100;100] и подставление полученных результатов в квадратное уравнение для проверки корней, вывод "Success" в случае успеха, и подробный результат в случае ошибки, поддерживает ввод количества желаемых тестов
                                               3.2) Использование коэффициентов и <<Эталонных>> решений из 
             текстового документа "unit_test.txt" и сравнивание их с полученными результатами, подробный анализ при несовпадении корней.
             4) help: выводит список команд для запуск режимов

!Запуск тестов:
1) Использовать случайные коэффициенты
./square_main.exe test
// выбрать режим 1

2) Использовать коэффициенты и эталонные решения из текстового документа "unit_test.txt"
./square_main.exe test
// выбрать режим 2
